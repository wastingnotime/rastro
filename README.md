# Rastro

Rastro explored motorcycle ownership, maintenance attention, and negotiated
owner-mechanic service orders through deterministic simulation.

Retired at the owner's request on 2026-10-13 and preserved as an archived
reference. Active development has stopped. Simulation source, tests, domain
documentation, refinement records, run evidence, history, and license remain
available.

- [Historical simulation](https://github.com/wastingnotime/rastro/blob/main/sandboxes/simulation/README.md)
